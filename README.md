# livro.iniciacao.a.religiao.dos.pretos-pdf

Este livro é 100% baseado na Lei Sagrada "Nsiku Wanlongo", como orientado pelo espírito
do Criador pelo seu enviado Kimbangu o Salvador da Raça Preta e registado pelo seu
escolhido Ne Tadi "A Pedra" nas Escrituras Sagradas KELUKA " O Despertar". 
Este livro foi orientado especificamente para acordar e ensinar a raça preta para que todos
voltem a sua identidade original como era desde os tempos remotos.
